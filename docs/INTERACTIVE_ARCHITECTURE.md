# Interactive Architecture Explorer

Open [`interactive-architecture.html`](interactive-architecture.html) directly in a modern browser. It is a standalone file with embedded styling and JavaScript, so it does not require a build process or external libraries.

The explorer provides:

- Production-target and current-v0.1 views.
- Search and architectural-plane filters.
- Component details, responsibilities, interfaces, and dependencies.
- Animated playback, realtime interaction, AI-generation, and commerce flows.
- Pan, zoom, fit, dark/light themes, print, and mobile layouts.

The same architecture page is embedded in the FastAPI application at `/architecture`.
